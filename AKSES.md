## 🚀 Alternatif - Jalankan Lokal

Jika link online tidak bisa diakses, jalankan di komputer lokal:

### Cara 1: Python (Recommended)
```bash
git clone https://github.com/fauzanzm204-max/aplikasi-arsip-surat.git
cd aplikasi-arsip-surat
python -m http.server 8000
# Buka: http://localhost:8000
```

### Cara 2: Download & Buka Langsung
1. Download repository sebagai ZIP
2. Extract folder
3. Double-click `index.html`
